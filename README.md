# 1099 Sales Rep Tracker Web PWA

A web-based PWA for independent commission-based sales reps.

## Features
- Start Work Day / End Work Day
- Location mileage tracking while the web app is open
- Receipt photo capture from iPad camera
- Sales and commission tracking
- Receipt/expense tracking
- Estimated tax dashboard
- Daily analytics after ending the work day
- Local browser storage
- Installable PWA support

## Run

```bash
npm install
npm run dev
```

## Deploy

Recommended: Vercel.

After deploying, open the website on iPad Safari, tap Share, then Add to Home Screen.
